# RTS.IntegraX — Documentation Rules

Toda alteração relevante deve possuir documentação.

---

# Obrigatório documentar:

- novas rotas
- novas tabelas
- novas variáveis .env
- mudanças arquiteturais
- integrações externas
- cron jobs
- autenticação

---

# ADR obrigatório quando:

- alterar arquitetura
- trocar tecnologia
- mudar autenticação
- mudar estratégia de banco
- alterar modularização
