# Guia de Contribuição

Obrigado por considerar contribuir com o **RTS.IntegraX**!  
Este guia explica como você pode ajudar no desenvolvimento.

## Como Contribuir

1. Faça um fork do repositório
2. Crie uma branch para sua feature ou correção:
   
```bash
git checkout -b minha-feature
```

3. Faça commits claros e descritivos
4. Envie um Pull Request

## Padrão de Commits

Recomendamos seguir o padrão de mensagens simples e consistentes, por exemplo:

- `feat: adiciona endpoint de criação de ticket`
- `fix: corrige erro ao atualizar status do item`
- `docs: atualiza README com instruções de instalação`

## Issues

- Use issues para relatar bugs, sugerir melhorias ou discutir novas ideias.
- Sempre descreva bem o problema ou sugestão.

## Pull Requests

- Teste o código antes de abrir o PR.
- Atualize a documentação relevante.
- Relacione o PR com uma issue, quando aplicável.

## Código de Conduta

Mantenha o respeito e colaboração. Críticas são bem-vindas, mas sempre de forma construtiva.
